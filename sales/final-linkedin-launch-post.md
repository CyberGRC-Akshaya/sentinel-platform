# Final LinkedIn Launch Post

I have built the first working version of Sentinel under Eye On Bits Pvt Ltd.

Sentinel is an AI-native assurance intelligence console for regulated environments.

The core problem it addresses:

Evidence exists, but it does not always prove what management claims it proves.

The current version supports:
- IT metrics evidence validation
- vendor / SOC 2 evidence challenge
- privacy and customer data evidence review
- SDLC and AI governance readiness
- IAM / access governance evidence review
- finding register export
- framework mapping rationale
- HTML examiner report export
- evidence upload intake

This is not another GRC repository.

The idea is to build an examiner-style intelligence layer that asks:
- Is the source of record clear?
- Is the denominator defensible?
- Is the reporting period aligned?
- Is the management conclusion supported?
- Are vendor responsibilities and CUECs understood?
- Is customer data handling evidenced?
- Is AI governance approval traceable?

This is still an MVP, but it already demonstrates the direction I care about: making governance, risk, audit, and security evidence more defensible.

Building in public. Feedback welcome from GRC, audit, risk, cybersecurity, privacy, TPRM, SDLC, and AI governance professionals.
