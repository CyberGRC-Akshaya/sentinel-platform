Error:
Unexpected token `main`. Expected JSX identifier.

Fix:
1. Final Room now uses normal JSX conditional rendering:
   {finalRelease && (...)}

2. Launch Room keeps the IIFE fallback wrapper correctly:
   {launchReadiness && (() => { ... return (...); })()}
