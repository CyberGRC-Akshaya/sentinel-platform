# Sentinel v2.2 Finding Command Center

## Upgrade summary

v2.2 adds an editable remediation command center.

## Adds

- Command Center tab
- Editable remediation register
- Owner, target date, status, management response, closure evidence, validation notes
- Workspace JSON export
- Remediation register CSV export
- Register status snapshot

## Why this matters

This changes Sentinel from a static report generator into a practical management follow-up workspace.
