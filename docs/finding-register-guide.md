# Sentinel Finding Register Fields

The v0.7 Finding Register CSV export includes:

| Field | Purpose |
|---|---|
| Finding_ID | Unique issue reference for tracking |
| Severity | Critical / High / Medium / Low |
| Risk_Domain | Metrics, TPRM, Privacy, SDLC, AI Governance, etc. |
| Affected_Item | Evidence item or artifact being challenged |
| Issue | What Sentinel identified |
| Evidence_Gap | What proof is missing |
| Examiner_Question | What audit/2LOD/examiner may ask |
| Remediation | Evidence or control improvement required |
| Framework_Relevance | Applicable control/regulatory relevance |
| Owner | To be assigned by management |
| Target_Date | Management remediation target |
| Status | Open / In Progress / Closed / Risk Accepted |
| Management_Response | Management explanation or response |

## How to use it

1. Run Examiner Review.
2. Click Download Finding Register.
3. Open CSV in Excel or Google Sheets.
4. Assign owners and dates.
5. Use it as a remediation tracker or consulting deliverable.
