# Sentinel v8.0 Executive Demo Room

## What v8.0 adds

v8.0 is the Executive Demo Edition. It stops feature sprawl and packages Sentinel into a buyer-facing demonstration workflow.

## Major capabilities

| Capability | Description |
|---|---|
| Executive Demo Room | Converts a saved review into a buyer-ready demo narrative |
| Demo Readiness Score | Scores how demo-ready the current review is |
| One-liner and positioning | Clarifies what Sentinel is and is not |
| Buyer Value Matrix | Maps Sentinel value to CISO, IT GRC, Audit, Privacy, TPRM, and AI Governance buyers |
| Seven-Step Demo Flow | Provides exact screen-by-screen walkthrough |
| Objection Handling | Prepares answers for expected buyer questions |
| Pilot Offer | Converts the product into a 2-week service/productized pilot |
| Portfolio Demo Room | Creates portfolio-level demo narrative |
| Final Build Recommendation | Defines what should happen after MVP freeze |

## New API endpoints

```text
GET /api/reviews/{review_id}/demo-room
GET /api/reviews/{review_id}/demo-room-html
GET /api/portfolio/demo-room-html
```

## Why this matters

This version is not just another feature.

It turns Sentinel into something you can explain, demo, sell, and improve with discipline.

v8.0 should be treated as the Final MVP Demo Edition unless a major production capability is being added.
