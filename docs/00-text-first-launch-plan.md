# Text-First Launch Plan

## Decision

Screenshots and demo video are intentionally skipped for now.

This launch path relies on:

- strong README
- written product narrative
- case study framing
- LinkedIn text launch
- targeted outreach
- working local demo available on request

## Why this is acceptable

A text-first launch is acceptable when the goal is to start conversations, not to publicly market a finished SaaS product.

## What must be done now

| Step | Action | Output |
|---|---|---|
| 1 | Apply v10.4 text-first pack | README and launch assets updated |
| 2 | Commit docs | GitHub repo cleaned |
| 3 | Publish LinkedIn post | Market signal |
| 4 | Send 10 pilot outreach messages | Feedback conversations |
| 5 | Prepare 1:1 live demo | Show localhost product only when requested |

## Risk

Without screenshots/demo video, conversion will be lower.

## Mitigation

Position this as an early product baseline and invite feedback from GRC/audit professionals.
