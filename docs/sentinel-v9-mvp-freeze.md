# Sentinel v10.0 Final Launch

## Decision

Feature development is frozen at v10.0.

The product now has enough demo-grade capability to support:
- portfolio presentation
- demo recording
- consulting pilot offer
- GitHub showcase
- product discovery conversations

## No more feature iteration until

1. The repo is clean.
2. The README is polished.
3. Screenshots are captured.
4. One demo script is rehearsed.
5. One demo video is recorded.
6. One pilot offer is written.
7. The current app runs without CSS/runtime issues.

## Allowed patch work

Allowed:
- bug fixes
- UI cleanup
- README improvements
- screenshot updates
- demo script improvement
- sample data improvements
- documentation cleanup

Not allowed:
- new random tabs
- new major feature ideas
- half-built integrations
- production claims
- fake AI claims
