# Sentinel v5.0 Control Atlas

## What v5.0 changes

This is a major upgrade.

Sentinel now includes a Control Atlas that maps evidence to control themes, expected evidence, missing control evidence, and examiner-style challenge questions.

## New capabilities

| Capability | Description |
|---|---|
| Control Atlas Mapping | Maps each evidence item to internal Sentinel control themes |
| Control Coverage Score | Scores how much expected control evidence is present |
| Missing Control Evidence | Lists artifacts needed for stronger defensibility |
| Challenge Question Bank | Generates reviewer-style follow-up questions |
| Control Atlas CSV Export | Exports item-to-control coverage and missing evidence |
| Control Atlas Register Fields | Adds control IDs to the remediation register |
| Portfolio Control Concentration | Shows which control themes recur across saved reviews |

## Why this matters

A finding register alone is not enough. A professional evidence review must answer:

1. What control objective is the evidence trying to support?
2. What artifact would prove the claim?
3. What is missing?
4. What question would an auditor, 2LOD reviewer, or examiner ask next?
5. Which control themes recur across the portfolio?

v5.0 starts answering those questions.
