# Sentinel v2.1 Evidence Intake Intelligence

## Upgrade summary

v2.1 upgrades Sentinel from evidence scoring to evidence intake intelligence.

## New output fields

- Intake Coverage Score
- Metadata Completeness Score
- Artifact Profile
- Missing Metadata
- Missing Intake Elements
- Intake Diagnostics CSV export

## New backend endpoints

```text
GET /api/intake-requirements
GET /api/scoring-dimensions
GET /api/framework-library
```
