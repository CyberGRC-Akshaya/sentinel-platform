# Sentinel Case Study Narrative

## Title

Building an AI-Native Assurance Intelligence Console for Evidence Defensibility

## Context

In highly regulated environments, governance teams often collect large volumes of evidence for audits, risk committees, vendor reviews, privacy reviews, SDLC governance, IAM reviews, and AI governance approvals.

The problem is not always the absence of evidence.

The problem is whether evidence is defensible.

## Problem Statement

Evidence packages often fail deeper scrutiny because they do not clearly prove:

- source lineage
- completeness
- calculation logic
- reporting-period consistency
- reviewer approval
- management conclusion support
- vendor reliance logic
- data handling boundaries
- AI governance approval and monitoring

## Solution Built

Sentinel was built as an AI-native assurance intelligence console that reviews structured evidence packages and generates:

- assurance score
- examiner-style findings
- evidence gaps
- challenge questions
- remediation guidance
- framework mapping rationale
- finding register
- HTML examiner report

## Technical Implementation

- Frontend: Next.js
- Backend: FastAPI
- Runtime: Docker Compose
- Automation: n8n + Google Workspace for agent command center
- Repo: GitHub
- Deliverables: Markdown, CSV, HTML, JSON

## Practical Use Cases

1. IT Metrics Validation
2. Vendor / SOC 2 Evidence Challenge
3. Privacy and Data Handling Review
4. SDLC Governance Review
5. AI Governance Evidence Review
6. IAM Evidence Review

## Business Value

Sentinel can be used as:

- GitHub portfolio asset
- consulting accelerator
- pre-audit evidence review tool
- productized service foundation
- recruiter proof of hands-on GRC engineering capability

## Key Differentiator

Most GRC tools store evidence.

Sentinel challenges whether evidence proves the claim.
