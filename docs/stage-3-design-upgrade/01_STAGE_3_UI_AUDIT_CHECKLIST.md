# Stage 3 — UI Audit Checklist

## Hero/Header

- Product name clearly visible
- One-liner is sharp and readable
- Version label does not dominate
- No amateur spacing
- No overcrowded hero text

## Navigation/Tabs

- Tabs are readable
- Active tab is obvious
- Labels are not confusing
- Too many tabs are visually managed

## Cards/Panels

- Consistent border radius
- Consistent padding
- Consistent section headings
- No cramped text
- Clear primary action per panel

## Buttons

- Primary actions stand out
- Secondary actions are calmer
- Dangerous actions are visually distinct
- Export actions are grouped logically

## Review Workflow

- Evidence input is understandable
- Output panel is visually structured
- Findings are readable
- Severity is prominent but not cartoonish

## Executive/Demo Areas

- Final Room feels intentional
- Board Pack feels senior-management ready
- Evidence Requests are owner-ready
- Delivery Kit feels like a productized service output
