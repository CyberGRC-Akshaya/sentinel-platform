# Stage 3 Screenshot Plan

## Screenshot rules

Take screenshots only after Stage 3 polish passes smoke test.

## Required screenshots

| Screenshot | Purpose |
|---|---|
| Final Room / Hero | Product positioning |
| Review + Output | Core workflow proof |
| Evidence Requests | Operational value |
| Board Pack | Executive value |
| Portfolio / Command Center | Management view |

## File names

Use these file names:

```text
01-final-room-positioning.png
02-review-output.png
03-evidence-requests.png
04-board-pack.png
05-portfolio-command-center.png
```

## Storage path

Save screenshots under:

```text
docs/stage-3-design-upgrade/screenshots/
```

## Do not capture

- browser error pages
- half-loaded screens
- scrollbars covering content
- old light version
- terminal windows
