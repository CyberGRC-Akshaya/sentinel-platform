# Sentinel Stage 3 Design Language

## Brand feeling

Sentinel should look like a premium assurance cockpit for risk, audit, GRC, and evidence defensibility.

## Visual traits

| Trait | Direction |
|---|---|
| Theme | Dark gradient control-room |
| Accent | Blue/cyan/purple, used sparingly |
| Background | Deep navy/black gradient |
| Cards | Soft borders, subtle elevation |
| Buttons | Strong primary, quieter secondary |
| Typography | Large confident headings, readable body |
| Tables | Calm, structured, not spreadsheet-heavy |
| Alerts | Severity visible but not noisy |

## What to avoid

- too much neon
- inconsistent colors
- default HTML look
- oversized paragraphs
- cramped panels
- random gradients
- too many competing CTA buttons
- college-project look

## Executive-grade wording

Use language like:

- Evidence defensibility
- Control Atlas
- Closure readiness
- Board pack
- Evidence request studio
- Portfolio risk view
- Review vault
- Examiner-style challenge

Avoid language like:

- toy demo
- simple dashboard
- random analyzer
- AI magic
