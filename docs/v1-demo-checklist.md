# Sentinel v1.0 Demo Checklist

## Before demo

- [ ] Docker running
- [ ] App opens at http://localhost:3000
- [ ] Backend health returns version
- [ ] Sample cases load
- [ ] Evidence upload works
- [ ] Run Examiner Review works
- [ ] JSON download works
- [ ] Finding Register download works
- [ ] HTML Report download works
- [ ] Local Review History appears

## Demo sequence

1. Show positioning: "Most GRC tools store evidence. Sentinel challenges whether evidence is defensible."
2. Show Sample Case Library.
3. Run IT Metrics Examiner.
4. Explain denominator and evidence lineage findings.
5. Show Framework Mapping Rationale.
6. Download Finding Register.
7. Download HTML Report.
8. Upload sample CSV evidence.
9. Show local review history.
10. Explain consulting use case.

## After demo

- [ ] Ask for feedback
- [ ] Ask which evidence review use case is most painful
- [ ] Offer focused pilot review
