# Sentinel v0.9 Release Notes

## Release name

Evidence Intake Console

## Adds

- Upload JSON / CSV / TXT / MD evidence files
- Browser-side conversion into Sentinel review package
- Local review history
- Evidence intake guide
- Sample CSV evidence file

## Why this matters

This makes Sentinel feel less like a static demo and more like a practical review workflow.

Users can now bring their own evidence text or CSV package and run the examiner review without manually building JSON from scratch.

## Current limitation

The parser is intentionally simple for MVP reliability. Production-grade document intake will require:
- PDF parsing
- DOCX parsing
- screenshot/OCR handling
- evidence metadata extraction
- secured upload storage
- authentication and access control
