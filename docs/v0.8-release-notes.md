# Sentinel v0.8 Framework Mapping Library

This release adds framework mapping rationale to Sentinel findings.

## What changed

- Backend now includes an internal framework mapping library.
- Findings now include:
  - framework
  - mapping type
  - rationale
  - expected evidence
- HTML reports include framework mapping rationale tables.
- Finding Register CSV includes framework rationale and expected evidence fields.
- IAM Evidence Examiner sample case added.

## Important note

Framework mappings are practical assurance mappings intended for product demonstration and consulting acceleration. They should be validated before use as formal regulatory citations in client deliverables.
