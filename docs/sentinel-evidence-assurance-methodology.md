# Sentinel Evidence Assurance Methodology

## Purpose

This methodology explains how Sentinel is used as an assurance accelerator for reviewing evidence packages, metrics, vendor submissions, privacy artifacts, SDLC records, IAM evidence, and AI governance materials.

Sentinel does not replace professional judgment. It structures and accelerates the challenge process.

## Review principles

### 1. Evidence must prove the claim

The existence of evidence is not enough. Evidence should demonstrate:
- source lineage
- completeness
- accuracy
- reporting-period relevance
- ownership
- reviewer approval
- control or risk objective linkage

### 2. Metrics must be defensible

For every metric, review:
- numerator definition
- denominator definition
- reporting period
- source system
- extraction criteria
- manual adjustment
- reviewer sign-off
- committee/reporting alignment

### 3. Vendor evidence must be reliance-ready

For SOC 2 and vendor assurance packages, review:
- report scope
- trust services criteria
- exceptions
- complementary user entity controls
- bridge letters
- customer responsibilities
- data processing boundaries
- incident notification obligations

### 4. Privacy evidence must show data reality

For PII/NPI/customer data, review:
- data flow
- processing purpose
- retention
- access boundaries
- vendor transfer
- deletion/destruction
- contractual safeguards

### 5. SDLC evidence must show governance completion

For release and development evidence, review:
- change record
- approval
- security testing
- risk acceptance
- exception handling
- deployment record
- production readiness

### 6. AI governance evidence must show controlled use

For AI use cases, review:
- AI inventory
- risk tier
- capability classification
- approved usage
- data handling
- monitoring
- incident escalation

## Sentinel review output

The review produces:
1. Executive summary
2. Assurance score
3. Findings
4. Evidence gaps
5. Examiner-style questions
6. Framework mapping rationale
7. Finding register
8. Remediation evidence request list
9. Management response tracker

## Client-ready review sequence

1. Intake evidence package.
2. Convert evidence into Sentinel review format.
3. Run Sentinel examiner review.
4. Review generated findings professionally.
5. Remove false positives or refine language.
6. Export HTML report and finding register.
7. Add consultant commentary.
8. Deliver executive summary and remediation tracker.
