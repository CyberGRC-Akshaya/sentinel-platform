# Live Demo Script Without Recorded Video

## Opening

Thanks for taking the time. I will show you Sentinel, an evidence defensibility workbench built by Eye On Bits Pvt Ltd.

The idea is simple: many teams have evidence, but they are not always sure whether that evidence is strong enough for audit, management review, 2LOD credible challenge, or examiner-style scrutiny.

## Positioning

Sentinel is not a GRC repository. It is a challenge layer above evidence packages.

## Demo path

1. Final Room
2. Run + Save Review
3. Control Atlas
4. Evidence Requests
5. Board Pack
6. Delivery Kit

## Key message

The value is not storing evidence.

The value is challenging weak evidence before someone more painful challenges it.

## Closing question

Would this kind of evidence defensibility review be useful before audit, management committee reporting, vendor review, AI governance review, or access review?
