# Sentinel v8.1 Delivery Kit Runbook

## Purpose

v8.1 freezes Sentinel as a demo-grade MVP and adds the delivery layer needed to show the product like a serious founder, consultant, or GRC product leader.

## What v8.1 adds

| Capability | Purpose |
|---|---|
| Delivery Kit tab | One place to package demo outputs |
| Delivery Readiness Score | Shows whether the current review is ready to demo or hand off |
| Client Delivery Checklist | Tracks what must be exported or prepared |
| Client Follow-up Note | Generates a ready-to-send post-review follow-up |
| Demo Asset Manifest | Exports a JSON manifest of demo artifacts |
| UI polish | Adds darker, more premium MVP demo styling |

## Recommended demo flow

1. Open Sentinel.
2. Run + Save Review to Vault.
3. Open Demo Room and explain the product.
4. Open Control Atlas and show mapped control evidence gaps.
5. Open Evidence Requests and show owner-ready evidence asks.
6. Open Board Pack and show executive communication layer.
7. Open Delivery Kit and export the checklist, follow-up note, and asset manifest.
8. Close with the Evidence Defensibility Sprint pilot offer.

## Stop condition

Do not add more feature tabs until:
- v8.1 runs cleanly
- README is polished
- screenshots are captured
- demo script is rehearsed
- GitHub repo is cleaned
- one demo video is recorded
