# Stage 2 No-Cursor Decision

## Decision

Cursor will not be required for Stage 2.

## Reason

- Budget sensitivity
- Avoid dependency on paid AI coding tools
- Reduce risk of large uncontrolled edits
- Keep changes deliberate and testable
- VS Code + ChatGPT + Docker + GitHub is enough

## Approved Stage 2 tools

| Tool | Use |
|---|---|
| VS Code | Main editor |
| ChatGPT | Guidance and exact replacement blocks |
| Docker | Local runtime/testing |
| GitHub | Version control |
| PowerShell | Commands/scripts |
| Notion | Product freeze and roadmap tracking |
