# No New Features Rule — Stage 2

## Rule

During Stage 2, do not add:

- new product tabs
- new scoring domains
- new backend endpoints unless required for stabilization
- new UI sections
- new AI claims
- new automation workflows
- deployment features
- commercial outreach assets

## Allowed

- bug fixes
- refactoring
- script cleanup
- Docker reliability
- README/runbook correction
- tests
- component extraction
- backend module extraction

## Why

Sentinel already proved the product concept. The immediate risk is not lack of features. The immediate risk is instability.
