# Demo Video Teleprompter

## Opening

Hello, this is Sentinel Evidence Defensibility Workbench by Eye On Bits Pvt Ltd.

Sentinel is an evidence defensibility challenge layer for audit, risk, compliance, TPRM, privacy, SDLC, IAM, and AI governance reviews.

It does not replace GRC repositories. It challenges whether evidence is strong enough for audit, management review, 2LOD credible challenge, or examiner-style scrutiny.

## Close

The value is not storing evidence. The value is challenging weak evidence before audit, regulators, senior management, or 2LOD credible challenge exposes it.
