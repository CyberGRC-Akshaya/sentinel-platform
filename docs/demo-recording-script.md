# Sentinel Demo Recording Script

## Target length

5 to 7 minutes.

## Opening

Hello, this is Sentinel Evidence Defensibility Workbench by Eye On Bits Pvt Ltd.

Sentinel is not a GRC repository. It is an evidence defensibility challenge layer. It helps risk, audit, compliance, TPRM, privacy, SDLC, IAM, and AI governance teams challenge whether evidence is strong enough for audit, management review, 2LOD credible challenge, or examiner-style scrutiny.

## Scene 1 — Final Room

Start with Final Room.

Say:

This screen captures the final product baseline: what Sentinel is, what it does, the capability stack, and the commercial offer. The goal is simple: turn weak evidence packages into findings, evidence requests, control mappings, board-ready narratives, and closure-ready remediation workflows.

## Scene 2 — Run review

Go to Review Input and click:

```text
Run + Save Review to Vault
```

Say:

Here I am running a sample evidence package. The review is saved into a local vault so it can be reloaded, exported, and tracked.

## Scene 3 — Control Atlas

Open Control Atlas.

Say:

This is where Sentinel moves beyond generic findings. It maps evidence to control themes, expected artifacts, missing evidence, and reviewer-style challenge questions.

## Scene 4 — Evidence Requests

Open Evidence Requests.

Say:

Findings are not enough. Teams need to know what to ask for, who owns it, what artifact is expected, and how closure should be validated. This screen turns findings into request-ready evidence asks.

## Scene 5 — Board Pack

Open Board Pack.

Say:

Technical findings need an executive communication layer. This board pack turns review results into an executive narrative, board questions, management prompts, and a 30-day action plan.

## Scene 6 — Delivery Kit

Open Delivery Kit.

Say:

This is the handoff layer. It generates delivery checklist, follow-up note, and demo asset manifest so the review can move into a real consulting or internal assurance workflow.

## Scene 7 — Close

Say:

The value is not storing evidence. The value is challenging weak evidence before audit, regulators, senior management, or 2LOD credible challenge exposes it.

Sentinel is currently a local demo-grade product baseline. The next true production stages would be AI reasoning, PostgreSQL and authentication, and workflow automation.
