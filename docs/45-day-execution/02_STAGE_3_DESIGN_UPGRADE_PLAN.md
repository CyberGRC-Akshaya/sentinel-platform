# Stage 3 — Design Upgrade Plan

## Objective

Make Sentinel feel like a premium risk/GRC product without destabilizing the working app.

## Scope

- keep dark premium theme
- improve hierarchy, spacing, and readability
- reduce clutter
- preserve workflow and tab behavior
- no new features
- no full rewrite
- test after every visual change

## Out of scope

- New tabs
- New scoring logic
- Real AI
- PostgreSQL
- Deployment
- Full Figma design system

## Stage 3 exit criteria

- UI looks cleaner
- all tabs still load
- no CSS regression
- no TypeScript build error
- screenshots can be captured
- Git commit pushed
