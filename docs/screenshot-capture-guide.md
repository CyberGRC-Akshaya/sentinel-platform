# Screenshot Capture Guide

## Browser setup

Use Chrome or Edge.

Recommended zoom:

```text
80% or 90%
```

Recommended window:

```text
Full screen desktop
```

Hard refresh before screenshots:

```text
Ctrl + Shift + R
```
