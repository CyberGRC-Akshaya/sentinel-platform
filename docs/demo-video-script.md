# 3-Minute Sentinel Demo Video Script

## 0:00 — Opening

This is Sentinel by Eye On Bits Pvt Ltd.

Sentinel is an AI-native assurance intelligence console for regulated environments.

The core idea is simple: evidence should not just exist — it should be defensible.

## 0:20 — Problem

In IT GRC, audit, vendor risk, privacy, SDLC governance, and AI governance, teams often have dashboards, screenshots, trackers, SOC 2 reports, release notes, and approval records.

But the real question is:

Does the evidence actually prove the control claim?

## 0:45 — Show product

This is the Sentinel console.

It includes sample cases for:
- IT Metrics Examiner
- Vendor & Privacy Examiner
- SDLC & AI Governance Examiner

## 1:05 — Run review

I will run the IT Metrics Examiner.

Sentinel reviews the evidence package and generates:
- assurance score
- rating
- findings
- severity distribution
- top risk domains
- examiner-style questions
- remediation guidance

## 1:45 — Explain finding

Here, Sentinel identifies a metric denominator inconsistency.

The issue is not just that two numbers differ. The issue is that management may not be able to prove population completeness, reporting-period consistency, and source-of-record reconciliation.

That is exactly the kind of challenge a strong audit, 2LOD, or examiner review would raise.

## 2:25 — Export

Sentinel can export JSON and HTML reports.

This makes the output usable for client review, executive summary, remediation tracking, and consulting workflows.

## 2:45 — Close

This is still an MVP, but the direction is clear.

Most tools store evidence.

Sentinel challenges whether the evidence is defensible.
