# Screenshot Capture Script

Use Chrome or Edge at 80–90% zoom.

Save screenshots under:

```text
github-assets/screenshots/
```

## Required screenshots

| Filename | Screen | Capture focus |
|---|---|---|
| `01-final-room.png` | Final Room | Product baseline, positioning, capability stack |
| `02-launch-room.png` | Launch Room | Readiness, scope, pilot offer |
| `03-demo-room.png` | Demo Room | Buyer value, demo flow, objection handling |
| `04-control-atlas.png` | Control Atlas | Control IDs, missing evidence, challenge questions |
| `05-evidence-requests.png` | Evidence Requests | Evidence asks, owner, validation test |
| `06-board-pack.png` | Board Pack | Executive narrative, board questions |
| `07-delivery-kit.png` | Delivery Kit | Checklist, follow-up, readiness |
| `08-portfolio-dashboard.png` | Portfolio | Portfolio summary and control concentration |
| `09-command-center.png` | Command Center | Register, owner, management response |
